# Bing Go!

เว็บบิงโกสำหรับเล่นกันในบ้าน เปิด `index.html` ในเบราว์เซอร์ได้ทันที

## วิธีเล่น

1. เจ้าบ้านใส่ชื่อและกด **สร้างห้องใหม่**
2. กด **แชร์ QR** ให้ผู้เล่นสแกน ใส่ชื่อ แล้วกดเข้าห้อง
3. เจ้าบ้านกด **สุ่มเลขถัดไป** เลขจะซิงก์ไปยังผู้เล่นทุกคน
4. ผู้เล่นแตะช่องตามเลข เมื่อครบแนวนอน แนวตั้ง หรือแนวทแยง กด **ตรวจ BINGO!**

เมื่อสุ่มเลข เว็บจะเลือกเสียงภาษาไทยจากอุปกรณ์โดยอัตโนมัติ กดปุ่มลำโพงมุมขวาบนเพื่อเปิดหรือปิดเสียง

ข้อมูลเกมจะถูกเก็บไว้ในเบราว์เซอร์ของแต่ละเครื่อง จึงกลับมาเล่นต่อได้หลังรีเฟรชหน้า

ระบบตรวจ BINGO จะนับเฉพาะช่องที่ผู้เล่นแตะและเป็นเลขที่ผู้สุ่มเรียกแล้วเท่านั้น

## เปิดให้เครื่องอื่นในบ้านเล่น

ใช้โปรแกรมเสิร์ฟไฟล์แบบใดก็ได้ เช่น ถ้ามี Python:

```powershell
python -m http.server 8080
```

จากนั้นเปิด `http://<ไอพีเครื่องผู้ให้บริการ>:8080` บนอุปกรณ์ที่เชื่อม Wi‑Fi เดียวกัน

กด **แชร์เกม** ด้านบนเพื่อแชร์ลิงก์หรือแสดง QR Code ให้ผู้เล่นสแกน

ระบบห้องใช้การเชื่อมต่อแบบ peer-to-peer เจ้าบ้านจึงต้องเปิดหน้าเกมค้างไว้ และทุกเครื่องต้องเชื่อมต่ออินเทอร์เน็ต หากเจ้าบ้านปิดหน้าเว็บ ห้องจะสิ้นสุด

## GitHub Pages

1. Push โฟลเดอร์นี้ขึ้น GitHub
2. ไปที่ **Settings → Pages**
3. เลือก **Deploy from a branch**, branch `main`, folder `/ (root)` แล้วบันทึก

เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repository>/`

## GitLab Pages

Push ขึ้น GitLab ได้เลย ไฟล์ `.gitlab-ci.yml` จะนำเว็บไปเผยแพร่ผ่าน GitLab Pages จาก branch หลักโดยอัตโนมัติ
